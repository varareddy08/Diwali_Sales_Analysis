# Diwali Sales Analysis

## Overview
This project focuses on analyzing Diwali sales data using Python to identify customer purchasing behavior, sales trends, and business insights. The project includes data loading, exploratory data analysis (EDA), data cleaning, and visualization techniques.

---

## Dataset
- Dataset: **Diwali Sales Data**
- Format: CSV file
- Contains customer demographics, product categories, purchase amounts, and sales information.

---

## Tools & Technologies
- **Jupyter Notebook**
- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**

---

## Project Workflow

### 1. Data Loading
- Imported dataset into Jupyter Notebook
- Loaded CSV data using Pandas
- Checked dataset structure and information

### 2. Exploratory Data Analysis (EDA)
- Analyzed customer demographics
- Studied sales distribution and purchasing patterns
- Generated summary statistics
- Identified trends and relationships in data

### 3. Data Cleaning
- Removed unnecessary columns
- Handled missing values
- Checked duplicate records
- Corrected data types for analysis

### 4. Data Visualization
- Created bar charts, count plots, and heatmaps
- Visualized customer purchasing behavior
- Compared sales across different categories

---

## Key Insights
- Identified top-performing product categories
- Analyzed purchasing behavior by gender and age group
- Found customer segments contributing most to sales
- Generated insights useful for business decision-making

---

## Conclusion
This project demonstrates the end-to-end data analytics process using Python, from data preprocessing to visualization and insight generation. It highlights how data analysis can support business understanding and decision-making.
